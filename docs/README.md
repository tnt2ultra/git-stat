# Документация Git stat

Данный каталог содержит проектную документацию по сервису `git-stat`.

Сервис предназначен для анализа репозиториев корпоративного GitLab и получения статистики по количеству строк Java-кода и Java-тестов в выбранных сервисах, группах сервисов и по сотрудникам.

## Назначение проекта

`git-stat` решает следующую практическую задачу:

- получить список сервисов из CSV-реестра;
- клонировать или обновить их Git-репозитории;
- проанализировать выбранную ветку;
- посчитать текущее количество строк в `.java`-файлах;
- разделить файлы на продуктовый код, тесты и исключённые артефакты;
- собрать commit-based статистику по сотрудникам;
- показать агрегированную статистику по группам, сервисам и авторам.

## Основной стек

- Java 25
- Spring Boot 4
- Spring Web
- Spring Data JPA
- Lombok
- H2
- Apache Commons CSV
- нативный `git`

## Краткий запуск

```bash
export GITLAB_TOKEN=ваш_токен_read_repository
export GITLAB_ALLOWED_HOST=gitlab.corp.example

mvn clean package
java -jar target/git-stat-0.0.1-SNAPSHOT.jar
```

После запуска интерфейс доступен по адресу:

```text
http://localhost:8080
```

H2 console:

```text
http://localhost:8080/h2-console
```

## Главные ограничения

- анализируются только файлы с расширением `.java`;
- используется только H2;
- история снимков LOC не хранится;
- статистика по сотрудникам основана на коммитах, без `git blame`;
- merge-коммиты исключаются из авторской статистики;
- за одну синхронизацию анализируется одна ветка;
- если выбранная ветка отсутствует в репозитории, синхронизация этого сервиса завершается ошибкой;
- в сервисе не реализованы авторизация пользователей, роли, аудит, PR-аналитика, релизы, стоимость, техдолг и поддержка других языков.
